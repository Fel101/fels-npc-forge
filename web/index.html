NPC Forge

A character generator for games. Roll a person, describe one in a sentence, or import a cast list, and get a data sheet, a portrait, expressions, a transparent full-body sprite, walk cycles and a model sheet, all drawn by Qwen-Image (or the built-in Mage-Flow, if you pick it) running in your own ComfyUI. Everything stays on this computer.

Where things are

Characters are saved as plain folders of PNG files plus an npc.json in the library folder next to the app, so any engine or script can read them. The Library tab lists them; the Create tab makes new ones.

Licence

The built-in Mage-Flow's weights are MIT, but Microsoft says the models are released for research and are not meant for use in a product or service, so it is not the default. Updates

NPC Forge asks GitHub for a newer release only when you press the button. Updating keeps your library, config.json and local folder; update.bat in NPC Forge's folder does the same.
