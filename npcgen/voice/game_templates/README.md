# Forge voice playback

Keep each delivered WAV together with its `clips/*.json` and `*.curves.csv`.
Clip times are seconds from the start of that WAV, not scene-global time. The JSON
includes its SHA-256, exact samples, duration, timing status and fallback reason.
No facial rig or character mesh is generated by this export.

`targets.json` names the 15 Forge viseme groups and an amplitude `mouth_open` group.
Rename the target values to your mesh's blend shapes/morph targets. Empty `sil`
means neutral rest (all mapped shapes zero). These are explicit artist-authored
targets, not an automatic ARKit or MetaHuman retarget. Combine groups that share a
target by summing and clamping to 1. Clear every mapped target each update so an old
vowel cannot remain active. Preserve the separate rest sprite frame.

## Godot 4

Copy `godot/forge_lip_player.gd` into a new project. Attach it to a Node, assign an
AudioStreamPlayer, and optionally a MeshInstance3D or AnimatedSprite2D. Edit its
`targets` to match `targets.json` and your mesh. Sprite animation `mouth` needs
the configured 15 frames; edit `sprite_frames` for your atlas. A missing mesh target
does nothing; create real shape keys in your art tool before using them.

Call `load_clip(json_path, wav_path)` and check its returned Error, then `play()`.
Use the helper's `seek(seconds)` and `stop()`; pause with
`audio_player.stream_paused = true`. Both loading and stopping clear old weights.
Its clock uses AudioStreamPlayer position corrected for mixing/output latency.
Connect `weights_changed` for portrait texture swaps or a custom character rig.
`weights_at(seconds)` also supports your own AudioStreamPlayer2D/3D clock.
The helper checks the delivered WAV hash before loading it.

Use the export's declared `method`: `visemes` samples the checked mouth groups;
`amplitude_fallback` drives `mouth_open`/jawOpen without asserting phoneme timing.
The final sample always rests. Add `*.json` and source `*.wav` to Godot's export
non-resource include filters when using FileAccess in a packaged game. Verify these
files are included; imported/compressed audio cannot pass the original byte hash.
This helper was written for the installed 4.7.2 engine; existing 4.6 projects must
keep their own pinned engine and validate compatibility independently.

## Unreal Engine

Import a `*.curves.csv` in Content Browser as **CurveTable**, with **Constant**
interpolation. The first column is the group name; subsequent headers are seconds,
and values are weights from 0 to 1. Linear interpolation can be chosen as an artistic
change, but differs between samples from the Forge/Godot preview.

Alternatively enable Unreal's Python Editor Script Plugin and explicitly run
`unreal/import_curves.py`, then call
`import_clip(json_path, pack_root, '/Game/ForgeVoices', 'MyVoiceLine')`.
`pack_root` is the directory containing `lines/` for a voice pack, or `audio/` for a
scene pack. It verifies the WAV and CSV against JSON before importing and refuses
overwriting an existing asset. Python is editor-only; the CurveTable is a runtime
asset and needs no Python in the shipped game. Import the WAV as a SoundWave.

In the character Blueprint, retain playback seconds for the active SoundWave.
Use AudioComponent **On Audio Playback Percent** times the imported sound duration;
when playing with a start offset, ensure the reported position matches the absolute
clip position. On seek/restart explicitly set the new position. On pause hold it;
on stop/finish clear all mapped morph targets. Evaluate every group with **Evaluate
Curve Table Row** at that position; sum weights for shared targets and call **Set
Morph Target** on the character's SkeletalMeshComponent. A missing target needs an
artist-created morph; this export does not promise MetaHuman facial compatibility.
For sprites combine weights sharing an image and select the greatest image weight.
Packs with character artwork include checked PNGs and rig JSON. Godot's
`load_sprite_rig(rig_json_path, pack_root)` builds the atlas and mappings directly.
This adapter uses dominant selection; use `weights_changed` for a weighted portrait
crossfade. Unreal can import the PNGs as Texture2D assets and select them with the
artist mapping and exported curves. For a scene,
start each beat's WAV and curves together at `beat.start / timeline.fps`.

Official interfaces:
- [Godot audio position](https://docs.godotengine.org/en/stable/classes/class_audiostreamplayer.html)
- [Godot blend shapes](https://docs.godotengine.org/en/stable/classes/class_meshinstance3d.html)
- [Epic CurveTable import](https://dev.epicgames.com/documentation/en-us/unreal-engine/data-driven-gameplay-elements-in-unreal-engine)

## Existing 3D mouth rigs

`character_rigs.mesh` links a checksum-bound rig JSON and original `model.glb`.
Its mapping names existing morphs, its jaw controls name an existing skin joint.
Jaw-only models vary opening; independent lip/tongue shapes require authored morphs.

Godot: instantiate that GLB, attach `godot/forge_mesh_mouth.gd` to a child of its
Skeleton3D, set `model_root`, then call `load_rig(json_path, original_glb_path)`
after entering the tree. Check the Error. Connect `forge_lip_player.weights_changed`
to `set_weights`. The SkeletonModifier3D applies the jaw after body animation and
updates mapped shapes across model meshes. Avoid a second writer to the same targets.

Unreal: sum group weights per mapped morph and clamp to 1. Sum jaw weights using
`config.jaw_amounts` (use 1 for `mouth_open`), clamp, multiply by `jaw_radians * jaw_sign`
and convert to degrees. Apply on `jaw_axis` to `jaw_bone` using Transform (Modify) Bone,
Add to Existing, Bone Space, after body animation. Check axis/direction against the
imported skeleton. Pause holds; stop clears; seek updates absolute audio seconds.
Import/retarget the skeleton with your existing art workflow; no AnimBlueprint is
generated. The jaw helper was executed on a real Forge GLB in Godot; Unreal runtime
jaw Blueprint setup remains an artist integration step.
